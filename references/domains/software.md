# Software Domain Pack

Use for software engineering, product engineering, scripts, APIs, frontend, backend, data tooling, DevOps, tests, debugging, and code review.

Core question:

> Where does AI substitute for bounded coding work, and where do human context, design judgment, testing, integration, and ownership remain necessary?

Look for:

- code generation;
- debugging;
- refactoring;
- tests;
- architecture;
- deployment;
- review;
- maintainability;
- security and privacy.

Typical exclusions:

- personal admin;
- general education not tied to software;
- creative/leisure;
- finance/legal unrelated to software work.

Never treat generated code as usable without verification. Prefer `RUN_TEST_COMPILE`, `CODE_REVIEW`, or `SECURITY_PRIVACY_REVIEW`.
